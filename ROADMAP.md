# Project Roadmap 🗺️

Future development plans for **CipherX AI**.

## Phase 1: Foundation (Current) ✅
- [x] Core Chat Interface with Streaming.
- [x] Reasoning Paths (Thinking blocks).
- [x] Basic Task Templates.
- [x] Security Vault with custom PIN.
- [x] PDF Transcript Export.
- [x] Dashboard Visualization.

## Phase 2: Enhanced Intelligence (Q3 2025) 🛠️
- [ ] **Native Audio Protocol**: Transition to Gemini 2.5 Flash Native Audio for ultra-low latency voice-to-voice.
- [ ] **Visual Generation**: Integrate Nano Banana models for on-demand image creation within the chat.
- [ ] **Multi-Speaker TTS**: Enable Joe/Jane multi-voice support for conversational scenario testing.
- [ ] **Grounding**: Add Google Search and Google Maps grounding tools for real-time information.

## Phase 3: Security & Ecosystem (Q4 2025) 🔒
- [ ] **Biometric Uplink**: WebAuthn integration for fingerprint/FaceID vault unlocking.
- [ ] **Custom Templates**: Allow users to save their own prompt templates to the Archive.
- [ ] **Encrypted Sync**: Optional encrypted cloud sync for multi-device access.
- [ ] **Mobile Native**: PWA optimization and standalone mobile wrappers.

## Phase 4: Enterprise Expansion (2026) 🏢
- [ ] **Team Clearances**: Shared organization accounts and permission tiers.
- [ ] **API Access**: Developer API keys for external integrations.
- [ ] **Local LLM Support**: Integration with WebGPU-based local models for offline privacy.
