# CipherX AI 🛡️🤖

**CipherX AI** is a high-security, professional-grade conversational intelligence platform designed with a modern cybersecurity aesthetic. Built for innovators, developers, and security professionals, it offers a seamless interface for interacting with advanced LLMs like Gemini 3 Pro and Flash.

## 🚀 Features

- **Cybersecurity Aesthetic**: A deep-void dark mode interface with neon-blue, green, and pink accents.
- **Real-time Conversation**: Streaming AI responses with a dynamic "typing style" and reasoning paths.
- **Security Vault**: Local encryption for sensitive data (passwords, notes, seeds) protected by a custom PIN.
- **Task Templates**: Specialized modules for CV optimization, business planning, marketing, and code generation.
- **Vocal Synthesis**: High-quality neural text-to-speech for audible AI interactions.
- **Protocol Export**: Generate professional PDF reports of conversation transcripts.
- **Network Dashboard**: Real-time visualization of system throughput and user distribution.
- **Premium Tier**: Access to Pro-level intelligence, unlimited credits, and priority server uplink.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Styling**: Tailwind CSS
- **AI Engine**: Google Gemini API (@google/genai)
- **Icons**: Lucide React
- **Charts**: Recharts
- **PDF Generation**: jsPDF
- **State Management**: React Hooks & LocalStorage Persistence

## 🔐 Security Information

CipherX AI prioritizes privacy.
- **Local Encryption**: Vault items and secret sessions are handled on the client-side.
- **Private Protocol**: Users can lock specific sessions behind a custom security PIN.
- **Audit Logging**: A transparent system log tracks critical events within the application.
